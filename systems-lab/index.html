3Open loop vs closed loop

Open loop system

The controller sends a command and never checks the result. There is no feedback. Example: a toaster runs for a set time whether the bread is pale or burnt.

Closed loop system

A sensor measures the output and feeds it back to the controller, which corrects until the goal is met. Example: a thermostat keeps checking the room and turns the heat on and off.

Test rig: send the arm to 90°

Both arms get the same order. The open loop arm runs its motor for a fixed time that was set with no load. The closed loop arm reads an encoder on its joint and keeps going until it reads 90°. Add a payload and run them.

4Digital vs analog

Digital signal

Has only two states: on or off, 1 or 0. It jumps between them with nothing in between. Example: a limit switch is either pressed or not.

Analog signal

Changes smoothly and can be any value in a range. Example: a potentiometer on a robot joint reports any angle, like 41.7°.

A computer can only store numbers, so it measures an analog signal and turns it into a number. VEX's V5 brain, for example, turns the voltage from an analog sensor into a number from 0 to 4095. The signal from the sensor is still analog.
