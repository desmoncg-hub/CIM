# Robot Configuration Lab

Interactive 3D work-envelope simulator for CIM (Hopewell Engineering & Manufacturing).

- Live page: https://desmoncg-hub.github.io/CIM/robot-lab/
- Five robots: Cartesian, Cylindrical, Polar, SCARA, Jointed Arm
- Explore mode: move joints, set hard stops, view the work envelope, label parts
- Challenges: five self-checking challenges; finishing all five unlocks a completion card with the student's name, date and wrong-answer count
